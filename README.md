# RN Motorcycles — Website prototype

A Next.js App Router conversion of the RN Motorcycles homepage concept.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Before launch

- Replace illustrative images with licensed and approved workshop photographs.
- Verify opening hours, prices, services, contact details, awards and any review claims against the business.
- Replace the current `mailto:` enquiry form with a secure server-side submission endpoint, validation, spam protection and a privacy notice.
- Configure canonical domain, indexability, legal pages and production analytics only after approval.
- Refactor the imported static homepage into accessible React components as the site grows.

The initial homepage is marked `noindex` until business facts and content are approved.
